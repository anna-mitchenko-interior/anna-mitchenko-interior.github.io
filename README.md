# Анна Митченко — портфолио

Статический сайт по утверждённому макету Figma, адаптированный для телефона, планшета и компьютера. HTML/CSS/JavaScript, без сборки на сервере. Файлы шрифта и изображения хранятся в репозитории.

## Публикация

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

После завершения публикации адрес сайта появится на этой же странице.

## Заявки

GitHub Pages не обрабатывает отправку форм на сервере. Форма проверяет поля и подготавливает письмо на `anmitchenko@gmail.com`. Посетитель нажимает «Отправить письмо Анне» и отправляет его из своей почтовой программы. На сайте также есть прямая ссылка на email. Никакая отправка не имитируется.

В макете нет текста политики обработки персональных данных. Соответствующая ссылка пока открывает email с запросом политики.

## Проверка

Проверены ширины 1600, 1024, 768, 390 и 360 px, загрузка изображений, мобильное меню и галерея. Сохранены все 100 текстовых слоёв Figma.
